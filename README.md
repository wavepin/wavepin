I enjoy taking an idea from *“wouldn't it be neat if…”* to something real, useful, and pleasant to use. This profile is a home for the things I make and the lessons I pick up along the way.

### How I like to build

- **Start with the useful part.** Make the core idea work, then earn every extra detail.
- **Keep curiosity in the loop.** Experiments are often where the best ideas begin.
- **Sweat the small stuff.** Good software should feel considered, not merely complete.
- **Leave room for delight.** Practical and playful can share the same screen.

### Right now

- Learning by making, breaking, and refining
